# Feedback Backend API

A RESTful API built with [NestJS](https://nestjs.com/) for collecting and managing user feedback. The API supports authentication, user management, and feedback CRUD operations.

## Features

- User authentication with JWT
- Secure feedback submission and retrieval
- MongoDB integration via Mongoose
- Input validation using class-validator
- Protected routes for feedback management

## Project setup

```bash
npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
